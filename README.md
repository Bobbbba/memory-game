# Memory Game

Браузерная игра на поиск пар. Игрок открывает карточки, запоминает их расположение и старается найти все совпадения за минимальное число ходов.

## Возможности

- Игровое поле 4×4 — 16 карточек (8 пар эмодзи), перемешанных случайным образом.
- Плавная 3D-анимация переворота карточек.
- Счётчики ходов и найденных пар.
- Модальное окно победы с итоговым результатом.
- Таблица лидеров: топ-10 результатов, сохраняется в `localStorage` и доступна после перезапуска приложения.
- Защита от дубликатов в таблице лидеров.
- Адаптивная вёрстка для мобильных экранов.
- Без внешних зависимостей.

## Как играть

1. Кликните по карточке — она перевернётся и покажет эмодзи.
2. Кликните по второй карточке:
   - если эмодзи совпали — обе остаются открытыми и подсвечиваются зелёным, счётчик найденных пар растёт;
   - если не совпали — через 0.9 секунды обе карточки переворачиваются обратно.
3. Продолжайте, пока не найдёте все 8 пар.
4. Ход засчитывается за каждую вторую открытую карточку, то есть за одну попытку угадать пару. Старайтесь сделать как можно меньше ходов.

Пока идёт анимация возврата несовпавшей пары, клики по остальным карточкам заблокированы.

## Интерфейс

**Хедер**

- Название игры.
- Кнопка **«Новая игра»** — сбрасывает партию и запускает новую с тем же размером поля.
- Кнопка **«Таблица лидеров»** — открывает модальное окно с топ-10 лучших результатов.

**Панель статистики**

- **Ходы** — текущее число сделанных ходов в этой партии.
- **Найдено пар** — прогресс вида `3 / 8`.

**Игровое поле**

- Сетка карточек с плавной 3D-анимацией переворота.
- Совпавшие пары подсвечиваются и больше не реагируют на клики.

**Модальные окна**

- **Победа** — показывает число ходов, кнопки «Играть снова» и «Таблица лидеров».
- **Таблица лидеров** — список лучших результатов (до 10 записей), отсортированный по возрастанию числа ходов. Из окна победы дополнительно доступна кнопка «Новая игра».
- Обе модалки закрываются кликом по затемнённому фону или по кнопке «Закрыть».

## Технологии

- **HTML5** — пустой `<body>`, вся разметка создаётся через JavaScript.
- **CSS3** — флексбокс, грид, 3D-трансформации, keyframes-анимации.
- **Vanilla JavaScript (ES5+)** — без фреймворков и библиотек.
- **localStorage** — хранение таблицы лидеров.
